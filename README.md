# Eclipse: Peladra

This scene introduces the water part of the Eclipse world. Every part in this world survives through trading, swapping goods with one another, and the water part - Peladra - needs enough funds to complete each type of trade. That is why the core idea of the game is simple: collect coins and turn them into funds that can later be spent on trading. You play as a coin that gathers other coins along the way, cashing them in as you pass through the bank, and the goal of each level is to reach a target number of coins. The path is not easy, though: thieves will try to knock away the coins you have collected, and a fiery pit waits below, where any coin that falls in burns up.
